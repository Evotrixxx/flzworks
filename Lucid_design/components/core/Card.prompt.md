Glass card — product tiles, list items, dashboard modules.

```jsx
<Card eyebrow="Sneakers" title="Vault Runner" meta="From $240" media={<div style={{height:180}} />}
```

Media goes edge-to-edge; text block always keeps 24px padding. Titles use display tracking (-0.03em).
